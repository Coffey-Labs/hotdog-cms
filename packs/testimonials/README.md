# Testimonials pack

A "Testimonials" section for any page of a HotDog CMS site: quotes from the
people you work with, each with a name and, if you like, a role or where
they're from.

    hotdog-cms pack add testimonials

Write the quotes in the section, or keep them in `data/testimonials.yaml` and
share them between pages (`from: testimonials`). Publish only what people
agreed to have shown, under the name they chose.
