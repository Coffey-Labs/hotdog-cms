# Calendar pack

Events for a HotDog CMS site: a page for each event, a list of what's coming
up at /events/, an "Upcoming events" section for any page, and a feed at
/events/calendar.ics that people subscribe to in their calendar app
(webcal). Each event also has an "Add to my calendar" file.

    hotdog-cms pack add calendar

See docs/packs.md in HotDog CMS for the event front matter.
