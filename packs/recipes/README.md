# Recipes pack

Recipes for a HotDog CMS site: a page for each with its photo, times,
servings, ingredients and numbered steps, a page at /recipes/ listing them,
and a "Recipes" section for any page. The details are also written as
schema.org Recipe data, which search engines use for recipe results.

    hotdog-cms pack add recipes

Ingredients and steps are lists in the front matter, so they're laid out the
same on every recipe; the story and tips go in the page itself.
