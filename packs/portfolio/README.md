# Portfolio pack

Show your work on a HotDog CMS site: a page for each project with its cover
picture, details (client, what you did, a link) and more pictures, a page at
/work/ listing every project, and a "Portfolio" section for any page.

    hotdog-cms pack add portfolio

Projects are Markdown files in `content/work/`, newest first by `date`.
Give each picture a description (`cover_alt`, and `alt` for the others).
