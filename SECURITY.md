# Security

## Reporting a problem

Email **security@coffeylabs.org**. Please don't open a public issue. Tell us
what you found, how to reproduce it, and which version you used
(`hotdog-cms version`). We'll answer within a few days, keep you posted, and
credit you when the fix ships, unless you'd rather we didn't.

## Supported versions

Fixes go into the latest release. Until 1.0, only the latest release is
supported.

## How HotDog CMS is built to be safe

[docs/security.md](docs/security.md) describes what HotDog CMS protects,
from whom, and how.
